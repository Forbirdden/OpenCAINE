## How to use OpenCAINE

### Install LISP compiler
Steel Bank Common Lisp is recommended

https://www.sbcl.org/platform-table.html

### Install QuickLisp
https://www.quicklisp.org/beta/#installation

### Install OptiCL using QuickLisp
```
(ql:quickload :opticl)
```

## How to use GUI
Ensure you have Python installed

### Install requirements using pip
```
pip install -r requirements.txt
```

### Run gui.py
```
python gui.py
```
